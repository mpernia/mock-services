# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability, please report it privately by emailing
the maintainer rather than opening a public issue.

**Do not** open a public issue for security vulnerabilities.

## What to include

- Description of the vulnerability
- Steps to reproduce
- Affected versions
- Any potential impact

## Response

You can expect an acknowledgment within 48 hours, and a fix timeline depending
on severity.

## Scope

This library is designed for **test environments only**. It launches fake
services on loopback interfaces and is not intended for production use.
That said, security issues are taken seriously and will be addressed promptly.
